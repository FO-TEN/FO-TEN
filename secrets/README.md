# secrets

LLM·환율 API 자격증명 파일처럼 **이미지에 구우면 안 되는 파일**을 두는 곳입니다.

`docker-compose.yml` 이 이 디렉터리를 컨테이너의 `/etc/foten` 으로 읽기 전용 마운트합니다. `Dockerfile` 에서 `COPY` 하지 않는 이유는, 이미지 레이어에 한 번 들어간 파일은 영구히 남아 이미지가 어디로 배포되든 함께 새어나가기 때문입니다.

**이 README 를 제외한 이 폴더의 모든 파일은 커밋되지 않습니다.** (`.gitignore` 참고)

## 주의

파일이 아니라 **디렉터리를 마운트**하고 있습니다. 파일 경로를 직접 지정했는데 호스트에 그 파일이 없으면 Docker 가 같은 이름의 빈 디렉터리를 만들어버려, "왜 안 되지?" 를 한참 찾게 되기 때문입니다.

## 지금은 비어 있어도 됩니다

현재 외부 연동 키는 `.env` 의 `LLM_API_KEY` / `EXIM_API_KEY` 환경변수로 주입합니다. JSON 자격증명 파일을 쓰는 연동이 추가되면 여기에 둡니다.
